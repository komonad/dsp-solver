# DSP Production Solver

`DSP Production Solver` 是《戴森球计划》的产线计算与配方求解工具。给定目标物品和每分钟产量，它会计算生产链所需的配方、建筑、原料和电力，并处理多产物配方带来的配平问题。

打开 [在线工作台](https://komonad.github.io/dsp-solver/)，选择游戏配置、添加生产目标，即可查看方案。调整配方、建筑或增产偏好后，工作台会自动重新求解。

## 功能

- 按占地、功耗或外部输入优化生产方案，支持强制配平和允许盈余
- 指定原矿、允许或禁用配方、禁用建筑，以及全局或逐配方的建筑与增产偏好
- 查看配方用量、建筑数量、功耗、原料需求、冗余产物和物品收支
- 在交互式物品流图中追溯生产链，关注指定物品的上游，或将某段上游设为视图外供
- 保存多套产线配置，支持复制、命名、切换和编辑求解快照
- 加载自定义数据集，并通过运行时导出器采集游戏及模组的物品、配方和图标

## 内置数据集

| 预设 | 游戏 / 模组版本 |
| --- | --- |
| 原版 | 游戏 `0.10.35.29131` |
| 原版 + 四级增产剂 | 原版数据，追加四级增产剂物品、配方和喷涂规则 |
| 星环组合 | 游戏 `0.10.35.29131`；星环 `1.0.20` + 更多巨构 `2.0.1` + 深空来敌 `3.4.24` |

原版与星环组合的游戏数据均于 `2026-10-14` 从运行时核对更新。原版数据还包含用于计算的采集、充电等虚拟配方，以及建筑和增产参数。星环组合包含 356 个物品、367 条配方和 337 个物品图标，采用模组组合加载后的配方与建筑能耗。

模组组合的配方和可用建筑可能与原版不同。例如，星环组合中的黑雾引力透镜只允许使用物质重组工厂生产。自定义数据集可在工作台的“数据管理与自定义”中通过静态路径加载。

## 本地开发

```bash
npm install
npm run build:all
npm run host
```

默认访问地址为 `http://localhost:8081`。开发时可运行 `npm run dev:web`；测试与类型检查分别使用 `npm test` 和 `npm run typecheck`。
