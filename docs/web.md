# Web 界面使用指南

`DSP Production Solver` 提供一个纯静态的浏览器工作台，用来加载数据集、编辑求解请求并查看结果。

## 基本流程

1. 从页头的“游戏配置”选择原版、模组组合或自定义数据
2. 添加目标物品与目标速率
3. 按需调整原矿、允许配方、禁用配方、禁用建筑、偏好建筑和增产偏好
4. 页面会在输入变化后自动重新求解，不需要手动提交
5. 在结果工作区查看资源、建筑和配方方案

## 页面布局

页头显示当前游戏配置，点击可切换游戏版本与模组组合。内置预设选择后自动加载；自定义路径、数据编辑器和缓存管理位于弹窗的“数据管理与自定义”中。

下方为“我的产线”卡片栏与三栏工作区：桌面端左侧是总览、物品总表与诊断，中间是配方与子图，右侧是产线设置。两条分隔线可拖动调整栏宽，浏览器会保存布局；双击分隔线或聚焦后按 Home 可恢复默认，左右方向键可微调。窄屏下单栏排列，产线设置可整体展开或收起。

### 配置卡片栏

支持多配置管理：创建、复制、重命名、删除和切换配置。每张卡片显示配置名称、数据集标签、求解状态徽章、建筑数、配方数和功耗。不同数据集的配置可共存，切换时自动加载对应数据集。

### 结果工作区

- **方案总览**：常驻显示建筑总数、总功耗和配方数；展开可查看目标产出速率、外部输入需求、冗余产出和建筑明细
- **全物品总表**：按分区（原矿输入、生产、外部输入、冗余）展示每种物品的生成、消耗与净值，点击可查看物品详情
- **诊断与审计**：求解状态、诊断信息、未满足偏好、回退求解选项

- **求解进度提示**（运行/已取消时显示）
- **物品流图**：交互式流向图（React Flow + ELK 布局），展示配方之间的物品流转关系。节点显示建筑图标和数量，边宽度与流量成正比。支持拖拽、缩放和截图
- **配方方案列表**：每张卡片展示一个配方的建筑、增产策略、功耗和主要输入输出速率；虚拟电力输入只参与求解平衡，不作为配方原料展示

### 产线设置（桌面端右侧吸附）

设置面板包含以下可折叠区段：

- **目标**：物品与目标速率（个/分），支持内联添加和编辑
- **原矿**：当前原矿物品列表（数据集默认 + 用户自定义），支持添加和移除
- **允许配方**：对某个物品仅允许指定配方
- **禁用配方**：排除指定配方
- **增产偏好**：全局和逐配方的增产剂偏好
- **禁用建筑**：排除指定建筑
- **偏好建筑**：指定配方优先使用的建筑
- **建筑参数**：研究站堆叠层数和传送带速度

顶部还有求解目标（最少占地/最低功耗/最少外部输入）、增产策略和等级的选择器。

### 物品详情浮层

点击结果中的物品图标会弹出左侧浮层，展示物品详情、生产来源，并提供标记为原矿、应用偏好配方、定位到物品总表等操作。

### 当前产线子图

在结果上方的“关注物品”选择器中选择当前产线的物品，或在物品详情中点击“关注”。关注范围包含所选物品的上游配方及其输入、副产物，到原矿输入停止；选择多个物品时显示范围的并集。配方列表和物品总表优先显示范围内条目，范围外条目及流图连线淡化。物品流图内也可直接修改关注选择。

关注栏显示范围内配方的建筑数和功耗，共享配方只计一次。所有速率和配方用量保留当前产线的数值，方案总览仍展示全产线总量。关注仅影响展示，不会重新求解或按目标分摊共享产能。移除关注或“清除关注”可恢复完整视图；切换配置或数据集会清空关注。

“淡化上游”将物品设为视图外供，追溯在该物品处停止，其专用生产链淡化。它可单独使用，也可与关注组合，例如关注宇宙矩阵并淡化电力上游。其他需求共用的配方仍保留，多产物配方也可能因其他产物需求继续显示。同一物品同时关注和设为外供时，外供边界优先。

流图以“视图外供”输入节点连接保留的消费配方，速率为这些配方的完整需求；原来的供给连线淡化。电力和喷涂耗材设为外供后也显示边界连线。物品详情中同样提供“淡化上游 / 恢复上游”。这些操作不改变产线设置中的原矿或任何求解参数；“恢复全部上游”或切换配置会清空视图外供。

## 数据集来源

工作台内置的数据集预设：

- `Vanilla` — 原版数据集
- `VanillaMkIV` — 原版兼容数据集，追加四级增产剂配置
- `OrbitalRing` — 轨道环扩展数据集
- `Custom` — 自定义路径，手动输入 dataset JSON 与 defaults JSON 的相对路径

浏览器通过相对路径 `fetch` 这些文件，所以自定义数据集需要和页面一起发布。

如果你要从游戏运行时导出模组数据，仓库里的 `tools/dsp-runtime-exporter` 可以导出 `items`、`recipes` 和逐物品 icon PNG。网页使用的是 atlas，所以导出后的 PNG 还需要离线打包成 atlas 再接入。

## 本地运行

```bash
npm ci
npm run build:web
npm run host
```

默认地址是 `http://127.0.0.1:8081`。

如果需要 watch 模式：

```bash
npm run dev:web
```

## 静态部署

执行：

```bash
npm run build:web
```

然后发布整个 `dist-web/` 目录即可。构建产物适合部署到普通静态文件服务器或 GitHub Pages。
